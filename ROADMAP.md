# Roadmap

Strategic project plan derived from [KANBAN.md](KANBAN.md).

## Current Focus

### OpenCode AI Orchestration (In Progress)

- Integrating OpenCode server as the primary planning and execution engine.
- Phase 1: Settings + Server Connection
  - Add configuration for OpenCode host, port, timeout, executable path, working directory.
  - Implement reusable OpenCode client wrapper in `lib/opencode.php`.
  - Detect availability of both OpenCode and Ollama instances on the dashboard.
- Phase 2: Command Execution UI
  - Add `/plan`, `/next`, `/debug`, `/review`, and `/document` command buttons across Agents, Kanban, and Roadmap views.
  - Execute commands through OpenCode for the active project.
  - Capture and display progress, output, errors, and commit hashes.
  - Prevent duplicate concurrent executions per project.
- Phase 3: Generator Workflow Preservation
  - Ensure `/plan` updates `ROADMAP.md` and `NEXT.md` (generated by OpenCode, not PHP).
  - Refresh planner views after successful `/plan`.
  - Show manual command instructions when OpenCode is unavailable.
- Phase 4: Command Template Management
  - Manage command template files in `.opencode/commands/`.
  - Preserve custom config keys during regeneration.
  - Synchronize templates into managed projects.

## Upcoming Priorities (Inbox)

### Application Architecture Refactor [urgent]

Major structural improvement to reduce `index.php` sprawl and follow MVC-like separation:

1. **Renderer layer** — Extract layout/view rendering into `lib/renderer.php`.
2. **Route extraction** — Move route mapping from `index.php` into Router or config.
3. **Helper consolidation** — Disperse helpers (`escape/e()`, `slugifyProject`, config readers, git helpers) across dedicated `/lib` modules.
4. **Controller layer** — Introduce `controller/` directory with per-route controllers (dashboard, kanban, roadmap, design, next, agents, projects).
5. **Persuasion only views** — Clean view files to presentational responsibility.

### Markdown Rendering Migration [high]

Centralize markdown rendering using Parsedown (already a Composer dependency):

- Create `lib/markdown_renderer.php` with caching and GFM support.
- Migrate roadmap, design, next, and agents page views to use the shared renderer.

### Project Repository Management [high]

Deepen git integration for managed projects:

- Dedicated project details page linking metadata, repository info, branch state, and sync status.
- URL sanitization (strip credentials/tokens).
- Git configuration via UI.

### Kanban UX Polish [high]

Incremental quality-of-life improvements to the board interface:

- Replace `alert()` calls with Bootstrap modals for confirmations and errors.
- Review column controls and standardize dropdown actions.

### Secondary Initiatives [normal]

- Reorganize Agents workspace layout and navigation hierarchy.
- Review and document Kanban column semantics (Todo / In Progress / Done).
- Archive tasks to dedicated `ARCHIVES.md` file.
- Bill of materials system based on `BOM.md`.
- Blog article workflow for LaswitchTech.com.
- Project CRUD management functions.
- Symlink-based project linking with file explorer.
- Move project metadata into `metadata.json` per project directory.
- Remove `active_project` concept from `config/projects.json`.
